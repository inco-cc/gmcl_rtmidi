---
title: OpenPort
---

```lua
RtMidiIn:OpenPort(number port)
```

## Description

Opens a port to receive messages from.

{{< note >}}
Only one port can be open at a time per [RtMidiIn]({{% ref "api/classes/RtMidiIn" %}}) instance.
{{< /note >}}

## Arguments

1. [number](https://wiki.facepunch.com/gmod/number) port  
The port number.
