---
title: OpenPort
---

```lua
RtMidiOut:OpenPort(number port)
```

## Description

Opens a port to send messages to.

{{< note >}}
Only one port can be open at a time per [RtMidiOut]({{% ref "api/classes/RtMidiOut" %}}) instance.
{{< /note >}}

## Arguments

1. [number](https://wiki.facepunch.com/gmod/number) port  
The port number.
