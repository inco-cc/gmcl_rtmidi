# Contributing

Contributions are welcome, but please read the following guidelines first.

## Issues

Please report all bugs and issues on [GitHub](https://github.com/inco-cc/gmcl_rtmidi/issues).

Alternatively, you can send an email to [blittle@inco.cc](mailto:blittle@inco.cc) ([PGP key](https://github.com/inco-cc.gpg)) and a GitHub issue will be created on your behalf. For your privacy, the issue will be credited anonymously, unless specified otherwise in your email.	

## Pull Requests

If you would like to contribute directly, you can create a [pull request](https://github.com/inco-cc/gmcl_rtmidi/pulls).

* Give your pull request a meaningful title.
* Please test your changes before submitting them.
* Follow the code style of the file(s) being changed. An [EditorConfig](.editorconfig) is included to help with this.
